## Commands (run in order)

| Step | Command | Notes |
|------|---------|-------|
| Codegen | `pnpm prepare` | Generates `styled-system/` (gitignored). Required before dev/build. |
| Dev | `pnpm dev` | Vite dev server on port 5173 |
| Typecheck | `tsc -b` | Part of build; catches TS errors before bundling |
| Build | `pnpm build` | Runs `tsc -b && vite build` |
| Test | `pnpm test` | Vitest (jsdom). Single file: `pnpm test -- src/components/ui/Counter.test.tsx` |
| Test watch | `pnpm test:watch` | |
| Lint | `pnpm lint` | ESLint with `eslint-plugin-solid` |
| Format | `pnpm format` | Prettier on `src/**/*.{ts,tsx,css}` |
| Clean | `pnpm clean` | Removes `dist`, `styled-system` |
| Reinstall | `pnpm reinstall` | Clean + remove `node_modules` + install from scratch |

## Framework quirks

- **SolidJS v2 (beta.25)** — error boundaries use `createErrorBoundary(fn, fallback)`, **not** an `<ErrorBoundary>` component.
- **`@solidjs/router`** — `createRouter` + `defineRoutes`, not `Router` component. Routes lazy-loaded with `lazy()`. Layout via render-prop: `<Router>{(props) => <Layout>{props}</Layout>}</Router>`.
- **`@solidjs/web`** is the JSX import source, set via `tsconfig.app.json` (`jsxImportSource`).
- **PandaCSS** — use `css()` from `@styled-system/css`. No class strings. Theme tokens: `accent`, `text`, `bg`, `border`, `code-bg`, `mono` (font). Semantic tokens support `_dark`.

## TypeScript (7.0.x)

- `erasableSyntaxOnly: true` — **no** parameter properties (`constructor(public x: number)`). Assign explicitly.
- `verbatimModuleSyntax: true` — type-only imports need `import type` keyword.
- `noUnusedLocals` / `noUnusedParameters` on — clean up unused identifiers.
- Path aliases: `@/` → `./src/*`, `@styled-system/` → `./styled-system/*`

## Architecture

- **Entry**: `src/index.tsx` renders `<App />` into `#root`
- **Routing**: `src/routes/index.ts` — `defineRoutes` with lazy `Home`, `About`, `NotFound`
- **Layout**: `src/layouts/MainLayout.tsx` — nav + `props.children.children` for outlet
- **App shell**: `src/App.tsx` — `ErrorBoundary` wrapping `createRouter`
- **Styling**: PandaCSS `css()` API only. No CSS modules, no Tailwind.
- **API layer**: `src/services/api.ts` — typed fetch wrapper, reads `import.meta.env.VITE_API_URL`
- **Global state**: Module-level `createSignal` in `src/stores/` files (e.g. `counter.ts`)
- **Env vars**: Typed via `src/types/env.d.ts` (`ImportMetaEnv`). Documented in `.env.example`.

## Testing

- Vitest with jsdom, globals enabled.
- Setup file: `src/test/setup.ts` imports `@testing-library/jest-dom`.
- Component tests use `@solidjs/testing-library`; `fireEvent.click` to simulate user interaction.

## Generated / excluded

| Path | Status |
|------|--------|
| `styled-system/` | Gitignored. Generated by `panda codegen`. Excluded from ESLint. |
| `dist/` | Build output. Excluded from ESLint + Prettier. |

## ESLint

- Ignores `dist/`, `node_modules/`, `styled-system/`, `*.cjs`
- `eslint-plugin-solid` flat config (no `typescript-eslint` — not compatible with TS 7)
